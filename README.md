# 🌸 Hát Tiếng Anh Cùng Mẹ (Sing English for Mom)

> **Trang web học tiếng Anh qua bài hát thiết kế riêng cho Mẹ:** Lời ca song ngữ Anh - Việt, phiên âm trợ âm tiếng Việt dễ hát, bí quyết nối âm luyến láy, giải thích ngữ pháp bài hát gần gũi, kèm MV ca sĩ hát mẫu và phòng thu âm giọng hát của Mẹ.

---

## 🌟 Tính Năng Nổi Bật Dành Riêng Cho Mẹ

1. **Phiên Âm Trợ Âm Tiếng Việt (Singing Phonetic Helper):**
   - Bên cạnh phiên âm quốc tế IPA, mỗi câu hát đều có dòng phiên âm tiếng Việt chuẩn hóa dễ đọc (Ví dụ: *"Such a feelin's"* ➔ *"Sắt-chờ phi-linh-z"*).
   - Đánh dấu cụ thể các vị trí **nối âm (linking)** giúp Mẹ hát liền mạch và không bị vấp.

2. **MV Ca Sĩ Hát Mẫu Chuẩn Từ YouTube:**
   - Mỗi bài hát đều tích hợp sẵn MV chính thức từ ca sĩ gốc để Mẹ vừa nghe giai điệu thực tế, vừa ngân nga theo nhịp bài hát.

3. **Cẩm Nang Ngữ Pháp Lời Bài Hát (Bilingual Grammar Insights):**
   - Phân tích trực tiếp các cấu trúc ngữ pháp có trong bài (*Present Simple, Past Simple, Can't help + V-ing, Used to, Câu điều kiện...*).
   - Giải thích ấm áp bằng tiếng Việt, giúp Mẹ hiểu sâu sắc cảm xúc của bài hát thay vì học vẹt.

4. **Phòng Thu Âm Của Mẹ (Voice Practice Studio):**
   - Mẹ có thể bấm nút **🔴 Bắt đầu thu** để tự tin cất giọng hát thử, sau đó bấm **▶️ Nghe lại** để cảm nhận sự tiến bộ mỗi ngày.
   - Hoàn toàn riêng tư, giọng thu được lưu trực tiếp trên thiết bị của Mẹ, không gửi đi bất kỳ đâu.

5. **Giao Diện Thân Thiện & Chữ To Rõ Ràng (Tối ưu cho iPhone & Samsung):**
   - Thanh điều hướng đáy màn hình (Bottom Navigation Bar) thuận tiện cho ngón tay cái.
   - 3 nấc chỉnh cỡ chữ (`A`, `A+`, `A++`) giúp Mẹ đọc rõ ràng trên điện thoại, iPad hoặc máy tính mà không cần đeo kính lão.
   - Tông màu hổ phách và gỗ ấm cúng, dịu mắt.

## 🚀 Hướng Dẫn Đưa Lên GitHub & Kích Hoạt GitHub Pages Miễn Phí (Trong 2 Phút)

Trang web được thiết kế bằng **Pure HTML5 + Modern CSS + Vanilla JavaScript (Zero-dependency)**, nghĩa là không cần cài đặt Node.js hay build code phức tạp. Chỉ cần đẩy lên GitHub là chạy ngay lập tức!

### Cách 1: Sử dụng Git & GitHub CLI (Khuyên dùng)

Mở cửa sổ dòng lệnh (Terminal / Git Bash) tại thư mục này và chạy các lệnh sau:

```bash
# 1. Khởi tạo Git repository (nếu chưa tạo)
git init
git add .
git commit -m "feat: initial Sing English for Mom package"

# 2. Tạo repository trên GitHub và đẩy code lên (dùng GitHub CLI)
gh repo create sing-english-for-mom --public --source=. --remote=origin --push
```

### Cách 2: Đẩy lên Repository GitHub đã có sẵn

Nếu bạn đã tạo một repo trống trên GitHub (ví dụ: `https://github.com/username/sing-english-for-mom.git`):

```bash
git init
git add .
git commit -m "feat: initial Sing English for Mom package"
git branch -M main
git remote add origin https://github.com/<tai-khoan-github-cua-ban>/sing-english-for-mom.git
git push -u origin main
```

### Cách Kích Hoạt GitHub Pages (Chỉ cần làm 1 lần):

1. Truy cập vào trang GitHub repository vừa tạo của bạn.
2. Bấm vào tab **Settings** (ở góc trên bên phải).
3. Ở menu bên trái, cuộn xuống mục **Pages** (dưới nhóm *Code and automation*).
4. Tại mục **Build and deployment** ➔ **Source**: Chọn **Deploy from a branch**.
5. Tại mục **Branch**: Chọn nhánh `main` (hoặc `master`), thư mục chọn `/ (root)`, sau đó bấm **Save**.
6. Đợi khoảng 1-2 phút, GitHub sẽ cung cấp cho bạn một đường link miễn phí trọn đời có dạng:
   👉 **`https://<ten-tai-khoan>.github.io/sing-english-for-mom/`**
7. Gửi link này cho Mẹ qua Zalo, Messenger hoặc lưu ra màn hình chính (Add to Home Screen) trên điện thoại của Mẹ!

## 🛠️ Hướng Dẫn Thêm Bài Hát Mới Vào Ứng Dụng

Để thêm bất kỳ bài hát nào mà Mẹ yêu thích (ví dụ: *I Have A Dream*, *My Heart Will Go On*, *A Whole New World*), bạn chỉ cần mở file `songs-data.js` và thêm một đối tượng bài hát vào mảng `SONGS_DATA`:

```javascript
{
  id: "ten-bai-hat",
  title: "Tên Bài Hát Tiếng Anh",
  artist: "Tên Ca Sĩ",
  year: 2000,
  difficulty: "Dễ (Mới bắt đầu)",
  level: "easy", // "easy" hoặc "medium"
  tempo: "Nhẹ nhàng, êm dịu",
  youtubeId: "ID_VIDEO_YOUTUBE", // Mã phía sau ?v= trên link YouTube
  theme: "Chủ đề bài hát",
  description: "Mô tả ngắn gọn về bài hát cho Mẹ...",
  grammarHighlights: [
    {
      title: "Tên điểm ngữ pháp",
      formula: "Công thức ngắn gọn",
      explanation: "Giải thích thân tình bằng tiếng Việt",
      singingExample: "Trích câu hát làm ví dụ"
    }
  ],
  vocalTips: [
    "Mẹo lấy hơi, mở khẩu hình, nhả chữ..."
  ],
  vocab: [
    { word: "Từ vựng", type: "noun/verb", ipa: "/ipa/", vi: "Nghĩa tiếng Việt", tip: "Mẹo đọc" }
  ],
  lyrics: [
    {
      en: "Câu hát tiếng Anh",
      phonetic: "Phiên âm trợ âm tiếng Việt",
      ipa: "/phiên âm ipa/",
      vi: "Dịch nghĩa tiếng Việt",
      singingTip: "Mẹo nối âm hoặc luyến láy",
      grammarNote: "Giải thích ngữ pháp nhanh câu này"
    }
  ]
}
```

Sau khi chỉnh sửa xong, bạn chỉ cần gõ `git commit -am "add new song"` và `git push` là trang web sẽ tự động cập nhật!
